# Access to Customer Data

## Requesting access

Access to production customer data requires a ticket with a business justification, approved by the data owner for that system.

## Time limits

Access is granted for at most 72 hours and is then revoked automatically. Open a new ticket if you need more time.

## Monitoring

Every access to customer data is logged. The security team reviews the access logs every month.

## Exporting data

Never copy customer data to personal devices. Customer data may be shared with a third-party tool only if a signed data processing agreement is in place.
