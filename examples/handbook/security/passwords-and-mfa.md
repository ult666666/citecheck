# Passwords and Multi-Factor Authentication

## Password manager

Use the company password manager for every work account. Passwords you create yourself must be at least 14 characters long; generated passwords are preferred.

## Multi-factor authentication

Multi-factor authentication (MFA) is required on every company account. Hardware security keys are required for production systems and administrator accounts; app-based codes are acceptable elsewhere. SMS codes are not allowed.

## Sharing and rotation

Never share your password with anyone, including IT staff. Passwords do not expire on a schedule; change a password immediately if you suspect it has been exposed.
