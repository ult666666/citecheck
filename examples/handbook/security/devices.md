# Device Security

## Company laptops

Every employee receives a company laptop, which is replaced every 3 years. Laptops must have full-disk encryption turned on and must lock automatically after 5 minutes of inactivity.

## Personal phones

Personal phones may be used for email and chat only after enrolling in the company's mobile device management. Customer data must never be stored on personal devices.

## Lost or stolen devices

Report a lost or stolen laptop or phone to the security team within 1 hour, through the security help channel or the IT hotline. The security team can wipe the device remotely.

## Software

Install software only from the company's approved software catalog. Requests for other software go through the IT ticketing system.
