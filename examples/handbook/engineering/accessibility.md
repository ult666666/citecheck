# Accessibility Standards

## Target

All customer-facing products must meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

## Before release

Every new user-interface feature is tested with a keyboard alone and with at least one screen reader before release.

## Color contrast

Body text must have a contrast ratio of at least 4.5:1 against its background. Large text and interface components need at least 3:1.

## Accessibility bugs

An accessibility bug that prevents a user from completing a task is treated as a high-priority bug and is fixed in the current sprint.
