# Open Source

## Using open-source software

Libraries under permissive licenses such as MIT, Apache-2.0 and BSD are pre-approved. Copyleft licenses such as the GPL need a review by Legal before use. AGPL-licensed code may not be used in products shipped to customers.

## Contributing

Employees may contribute to open-source projects related to their work during working hours, with their manager's approval. Signing a contributor license agreement on behalf of Larkmoor requires approval from Legal.

## Releasing company code

Publishing Larkmoor code as open source requires approval from the chief technology officer and a security review.
